## 设定：这段感情是一个游戏存档

血条、对话框本来就在片子里，这版把它做成整支片的设定。开头读档失败，她从存档里碎掉；结尾用游戏界面清算，最后回到标题画面，只剩"新的开始"。

**开头每隔几秒必须有一个没见过的东西**：标题 → 读档 → 她碎掉 → 世界垮掉 → 往下掉 → 落地 → 气泡砸人 → 整屏大字 → 水淹 → 水下的门 → 冒出水面 → 碗里划船 → 大月亮 → 气泡冰雹 → 大心 → 保险库 → 大字"爱"。
